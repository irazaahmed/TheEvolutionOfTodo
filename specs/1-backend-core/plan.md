## Phase 1: Data Model and API Contract Design

### 1.1 Data Model Design

**DM1.1: Todo Task Entity Definition**
- Define SQLModel schema for Todo Task with fields:
  - id (UUID/int primary key)
  - title (string, required)
  - description (string, optional)
  - completed (boolean, default false)
  - user_id (foreign key reference to user)
  - created_at (timestamp)
  - updated_at (timestamp)

**DM1.2: User Entity Definition**
- Define SQLModel schema for User with fields:
  - id (UUID/int primary key)
  - created_at (timestamp)
  - updated_at (timestamp)

**DM1.3: Relationship Mapping**
- Establish one-to-many relationship between User and Todo Task
- Define foreign key constraints
- Determine cascade behaviors for related operations

### 1.2 API Contract Design

**AC1.1: List Tasks Endpoint**
- Method: GET
- Path: /users/{user_id}/tasks
- Parameters: None required, optional query params for filtering/sorting
- Response: Array of Task objects
- Status Codes: 200 (success), 404 (user not found), 500 (server error)

**AC1.2: Create Task Endpoint**
- Method: POST
- Path: /users/{user_id}/tasks
- Request Body: TaskCreate schema with title, description
- Response: Created Task object with ID and timestamps
- Status Codes: 201 (created), 400 (validation error), 404 (user not found), 500 (server error)

**AC1.3: Get Task by ID Endpoint**
- Method: GET
- Path: /users/{user_id}/tasks/{task_id}
- Response: Task object
- Status Codes: 200 (success), 404 (task not found), 500 (server error)

**AC1.4: Update Task Endpoint**
- Method: PUT
- Path: /users/{user_id}/tasks/{task_id}
- Request Body: TaskUpdate schema with optional fields
- Response: Updated Task object
- Status Codes: 200 (updated), 400 (validation error), 404 (task not found), 500 (server error)

**AC1.5: Delete Task Endpoint**
- Method: DELETE
- Path: /users/{user_id}/tasks/{task_id}
- Response: Empty or confirmation message
- Status Codes: 204 (deleted), 404 (task not found), 500 (server error)

**AC1.6: Toggle Task Completion Endpoint**
- Method: PATCH
- Path: /users/{user_id}/tasks/{task_id}/toggle
- Response: Updated Task object with toggled completion status
- Status Codes: 200 (toggled), 404 (task not found), 500 (server error)
