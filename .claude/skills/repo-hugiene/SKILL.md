# Skill: Repository Hygiene

## Purpose
This skill maintains a clean, consistent, and phase-isolated repository structure.

## When to Use
Use this skill whenever files, folders, or project structure changes occur.

## Inputs
- Repository structure
- Active hackathon phase
- Existing folder conventions

## Procedure
1. Verify files are placed in the correct phase folder.
2. Ensure no cross-phase leakage occurs.
3. Enforce consistent naming conventions.
4. Detect duplication or orphaned files.
5. Recommend cleanup actions if required.

## Output
A confirmation of repository cleanliness or a list of required fixes.

## Quality Rules
- Phase isolation is mandatory.
- Structure consistency must be enforced.
- Repository must remain readable and auditable.
