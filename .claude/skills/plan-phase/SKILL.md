# Skill: Plan Hackathon Phase

## Purpose
This skill creates a clear execution roadmap for the active hackathon phase.

## When to Use
Use this skill at the start of each hackathon phase.

## Inputs
- Active phase
- Phase requirements
- Existing specifications

## Procedure
1. Identify mandatory deliverables for the phase.
2. Break work into ordered steps.
3. Map steps to agents and skills.
4. Highlight risks and dependencies.
5. Define completion criteria.

## Output
A structured phase execution plan.

## Quality Rules
- Plan must be phase-scoped.
- Dependencies must be explicit.
- No implementation work included.
