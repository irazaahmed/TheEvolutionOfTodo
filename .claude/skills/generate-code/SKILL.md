# Skill: Generate Code From Specification

## Purpose
This skill generates code strictly from an approved specification using the appropriate implementation agent.

## When to Use
Use this skill only after a specification has been validated and approved.

## Inputs
- Approved specification file
- Target programming language or framework
- Active hackathon phase

## Procedure
1. Read and understand the specification fully.
2. Select the correct implementation agent (Python, FastAPI, Next.js, etc).
3. Generate code only for what is explicitly specified.
4. Place generated code in the correct phase folder.
5. Do not modify the specification.

## Output
Generated source code aligned exactly with the specification.

## Quality Rules
- No extra features allowed.
- No speculative behavior allowed.
- Code must reflect the specification one-to-one.
