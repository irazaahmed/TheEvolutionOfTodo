# The Evolution of Todo  
Hackathon II – Spec-Driven Development with Reusable AI Agents

## About the Project

**The Evolution of Todo** is a single product designed to demonstrate modern AI-first and spec-driven software development.

The project begins as a simple Python in-memory console Todo application and evolves step by step into a cloud-native, AI-powered, event-driven system across multiple hackathon phases.

All development is performed using **Claude CLI** and **Spec-Kit Plus**, following strict **Spec-Driven Development** principles. Manual coding is explicitly prohibited. Every feature is defined through written specifications, validated, and then generated by AI.

The system is governed by reusable AI agents for planning, coordination, and enforcement, and reusable skills for repeatable workflows. This approach ensures consistency, auditability, and controlled evolution across all phases.

This repository represents an architecture-focused, AI-native approach to building and evolving software systems.
